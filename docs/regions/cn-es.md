- 名称与代码（M43–M46，用户 2026-10-30 两轮问答中定）：长夏群岛领地 / Everlong Summer Islands，伊武兰语 Imimu Selovaru（「长久的夏天的群岛」）；930000、CN-ES，ISO 3166-1 为 ES / ESI / 904。12 市 64 区、1200 万人、陆地约 90 万 km²，比例尺 4（`world/generator/cn-es.yaml`）。旗 `everlong_summer`：上半红金相间的十三道太阳光芒和半轮太阳，下半绿色梯田台阶，底部蓝色海浪。法官 11 人。
- 地理：北纬 2–12° 的热带季风气候，雨季旱季分明，基本没有台风和地震（所以没有火山），没有冰川。一座东北—西南走向的长岛（约 2400 × 350 km），西南端外是基鲁迈群岛（6 座岛约 5.5 万 km²，先向南再向东弯成弧线，和主岛之间海面宽约 140 km）；中脊蒂拉凯苏山脉是古老的褶皱山脉，最高峰乌拉韦劳峰 3179 m，山顶有高山草甸和云雾林；东北段另有乌诺凯苏山地。首府米雷兰在哈努帕拉高原上，紧挨翁贝尔哈努湖（约 1590 km²）；大片雨林国家公园；中脊山坡有大规模水稻梯田。哈努西鲁河约 1400 km，是世界最长的河，从中脊西坡流向西南，在三角洲入海；生成器在三角洲加了一条低谷，让河口离萨伦纳姆老城不太远（萨鲁凯区做港区）。地貌放在 `cn-es-coast.yaml`、`cn-es-relief.yaml` 和河流文件里。
- 人口：本地人约一半，其余是国际移民（中国其他省份约三成，其余来自世界各地）；大城市移民多，小城市本地人多。中文为通用语，英文和伊武兰语都是官方语言，三语并用，政府提供三语服务。不设原住民自治区，本地人和移民同一套制度。各市「移民 / 本地人约占几成」按构建出的伊武兰语比例写。
- 伊武兰语（Ivuran，`art-x-ivuran`，名片缩写「伊」/ IVR，自造）：南北两大方言，北部为南岛语式（开音节、前后缀、重叠表复数），南部为达罗毗荼式（卷舌音、-am / -ur 等长词尾）；雅称、王城和寺庙名用梵语式的自造词根；不直接用现实词汇。中文名音译，英文直接用伊武兰语拼写（Sarunnam City、Lake Ombelhanu）。
  - 基本词：hanu 大、tira 古老、kesu 山（山脉）、pala 高原、siru 河、ombel 湖、kari 山谷、uno 矿石、lomi 森林、mai 珍珠、nalu 浪、kiru 串、tilu 三、talu 停泊、evu 大家、tola 家、ura 高、velau 云、vila 光、kila 明亮、nu 沙、vahira 远方的岩石、imimu 长久、selo 夏、varu 群岛（岛）、lorai 线、pitlorai 地铁、taluvan 车站、luma 货物。地形通名接在专名后：lavu 湾、ruvai 岬、tiva 海峡、tuma 峰、vasu 山口、kalu 河口，-ni 表「小」；中文是专名音译加通名，英文是「X Bay」「Cape X」「Mount X」「X Pass」。
  - 交通词：vesupelavu 高速公路、pelavu 领道、vesulorai 高速铁路、vilalorai 磁悬浮（「光之线」）、lumalorai 重载铁路（「货物之线」）、uriva 环。车站「Taluvan ×」，货运站「Lumataluvan ×」，地铁「× Pitlorai」，地铁线「× Lorai N」。
  - 街名：伊武兰语的通名在专名之前（Sevu Nalu「浪街」），中英文仍是专名在前。干道 Pelavu / Hanusevu / Sevu，次干道 Sevu / Sorai / Hanusorai，支路 Sorai / Kilai / Toruva / Pisevu / Taroma / Sevuni；编号路 Taruvo / Lintavo。街名主题 tropic（伊武兰语词根）、flora、fauna（后两套只有中英文），「祖国城市」照常保留。

- 城市：最大城市萨伦纳姆在西南大河三角洲，是古王国的中心，350 万人，有瓦什塔赖旧王城、老街区和水上市场，外围是摩天楼 CBD；首府米雷兰是高原大湖畔新建的行政城市，40 万人；工业带在东南沿海，梯田在中脊山地。
- 埃武托拉公社（`commune`）：东北部海岸，100 万人、2 万 km²，名称用伊武兰语，意为「大家的家」。公社自治、自定税率（财政部中央财政事务司按协议结算），居民综合税负超过 80%；政务院只管外交、国防等少数事务。住房、公交、水电网、教育、医疗、托育、养老全部免费，汽车等昂贵物品也免费、按需取用；公共食堂、公共洗衣房、共享工具库；劳动贡献积分代替大部分工资，最高与最低收入之比不超过 3 倍；企业以集体所有和合作社为主，居民议事会直接民主；每周工作四天。立法机构是公社人民代表大会（代表由街区大会推选，日常事务交公社管理委员会），现由人民公社共产主义运动单独执政、出任主任，国际共产党为最大反对党（M105，用户 2026-11-07 要求，领地层面尽量不变：公社运动的领地目标得票因此调高，在埃武托拉之外几乎没有支持者）。

- 经济与政策：农业（水稻梯田、香料、可可和咖啡、热带水果、海水养殖；不种油棕）、工业（半导体与电子、造船、生物医药、镍矿到电池和新能源车的产业链）、服务业（旅游、港口转运与物流、热带医学研究、数字服务）三者均衡。高税收、高福利、高监管：全民医保（公共健康保险司）、免费教育到大学、长期带薪育儿假、全民基本收入（公共福利司按月发放）、土地公有长期租用（自然资源部代表领地出租，建设部管住房转租和租金）、严格的环境劳动食品安全监管。人民幸福感高，写在名片文字里，不另设指标。古王国留下寺庙和宫殿遗址；信仰多元但城市世俗化，节庆多。岛链是海岛度假和潜水、本地人传统聚居和珊瑚礁海洋保护区。
